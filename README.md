Програма для створення та керування базою даних обліку
================================

Додаток для ведення профілактичного обліку з графічним інтерфейсом на основі PySide6.

## ⚡ Швидкий старт

```bash
git clone git@github.com:Wendors/ProfsOV.git

cd ProfsOV
pip install -r piplist.txt

python Baza.py
```

## 🔧 Системні вимоги

- Python 3.8+
- PySide6
- Linux/Windows/macOS
